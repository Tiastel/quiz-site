# 🧠 DeepQuiz (상식부터 심오한 지식까지)

> 사용자가 입력한 어떤 주제든 기초 상식부터 최고난도 심오한 지식까지 4지선다 퀴즈를 출제하고, 실시간 점수 채점과 고품격 해설 및 심층 지식 팁을 제공하는 반응형 퀴즈 웹 애플리케이션 완성본입니다.

---

## 🌟 핵심 특징

### 1. 🎯 주제 입력 & 지능형 문제 생성 (Dual-Engine)
- **자유 주제 입력**: 천문학, 역사, 양자역학, 인공지능, 커피, 영화, 철학 등 어떤 주제든 실시간 분석
- **엄선된 12대 지식 프리셋 (총 96개 정밀 검증 큐레이션 문항)**:
  - 🌌 **우주 & 천문학**: 태양계 기본 상식부터 블랙홀 사건의 지평선, CMB 복사, 렌제-티링 효과
  - 🏛️ **한국사 탐구**: 세종대왕과 훈민정음부터 대동법의 경제사, 예송논쟁(현종 시기 인선왕후 상복 복제), 신라 골품제
  - 💻 **AI & 컴퓨터 과학**: 인공신경망 기초부터 트랜스포머 Self-Attention, P-NP 문제, 양자 중첩 큐비트
  - ⚛️ **물리학 & 양자역학**: 뉴턴 역학부터 광전효과, 불확정성 원리, 벨의 부등식, 힉스 메커니즘
  - 🧭 **철학 & 사상**: 소크라테스 산파술부터 데카르트 코기토, 칸트 정언명령, 비트겐슈타인 언어게임, 실존주의
  - 🌍 **세계사 & 문명**: 함무라비 법전부터 베스트팔렌 조약, 르네상스 메디치 가문, 쿠바 미사일 위기
  - 🧬 **생명과학 & 의학**: DNA 이중나선부터 CRISPR-Cas9, 텔로미어, 후성유전학(DNA 메틸화), mRNA 백신
  - 📈 **경제 & 금융**: 수요공급 균형부터 내쉬 균형, 양적완화, 블랙-숄즈 모형, 행동경제학 넛지
  - 🎨 **미술 & 문화예술**: 모나리자 스푸마토 기법부터 뒤샹 샘(레디메이드), 아우라의 상실, 바우하우스 건축
  - 🧠 **심리학 & 인지과학**: 파블로프 조건반사, 밀그램 복종 실험, 대니얼 카너먼 시스템 1·2, 신경가소성, 확장된 인지 가설
  - 📚 **문학 & 세계 고전**: 호메로스 오디세이아, 셰익스피어 4대 비극, 단테 신곡, 카프카 변신, 도스토옙스키 대심문관, 롤랑 바르트 저자의 죽음, 바흐틴 다성성
  - 🌏 **지구과학 & 환경생태**: 판구조론과 대륙이동설, 오존층 자외선 차단, 열염순환, 러브록 가이아 이론, 밀란코비치 주기, 인류세, 행성 한계선, 대산화 사건

## 🎮 5대 게임 모드 (Game Modes)

1. **클래식 탐구 (Classic)**: 상식(Level 1)부터 심오한 지식(Level 4)까지 순차적으로 정복
2. **오늘의 퀴즈 (Daily Challenge)**: 매일 자정 갱신되는 5대 핵심 영역 챌린지 & 스트릭 누적
3. **서바이벌 서든데스 (Survival)**: 하트 3개(`❤️❤️❤️`)로 무한히 오르는 극한의 서든데스
4. **타임어택 60초 (Time Attack)**: 60초 스피드런! 정답 시 +3초 보너스 및 마지막 6초 긴박한 째깍음 사운드
5. **3D 플래시카드 (Flashcards)**: 에빙하우스 망각곡선 기반 뒤집기 암기 및 복습 모드

---

## ⌨️ 키보드 단축키 (Keyboard Navigation)

- `1, 2, 3, 4`: 1~4번 보기 즉시 선택
- `Enter / Space`: 정답 확인 후 다음 문제로 이동 (플래시카드: 카드 뒤집기)
- `F`: 50:50 찬스 발동 (오답 2개 제거)
- `H`: 힌트 찬스 발동
- `B`: 현재 문제 북마크 저장/해제
- `M`: 집중 앰비언트 BGM 온/오프 (실시간 이퀄라이저 파형 연동)
- `?`: 단축키 도움말 모달
- `ESC`: 열려 있는 팝업 모달 닫기

## 🚀 실행 및 테스트 방법

### 1. 개발 서버 실행 (현재 구동 중)
```bash
# 로컬 개발 서버 시작 (포트 5173)
npm run dev
```
브라우저에서 `http://localhost:5173/` 접속하여 즉시 퀴즈를 즐기실 수 있습니다.

### 2. 프로덕션 빌드 & 테스트
```bash
# TypeScript 타입 체크 및 프로덕션 번들 빌드 (~400ms)
npm run build

# 747개 문항 무결성 및 시스템 자동화 검증 스크립트 실행
npx tsx scripts/verify-quiz.ts
```

## 💡 Gemini API 키 연동 (선택 사항)
1. 우측 상단의 **[AI 열쇠 아이콘]** 버튼을 클릭합니다.
2. [Google AI Studio](https://aistudio.google.com/app/apikey)에서 발급받은 무료 API 키를 입력하고 저장합니다.
3. API 키는 브라우저의 `localStorage`에만 안전하게 보관되며, 임의의 독특한 주제도 실시간 AI로 무한 출제됩니다.
4. 키를 입력하지 않더라도 내장된 96개의 최고품질 큐레이션 문제와 스마트 합성 엔진이 기본 작동합니다.
